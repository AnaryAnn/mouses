СЫЧИНАЯ ОХОТА V4

Что изменилось:
1. Каждая неделя вторник-понедельник хранится на отдельном листе Google Sheets.
2. Новый лист создается автоматически при первом обращении на новой неделе.
3. Все 12 имен уже находятся в недельном листе в алфавитном порядке.
4. На сайте есть поиск имени по введенным буквам.
5. Командная цель задается во вкладке "Настройки".
6. Цель записывается в B2 недельного листа. Ее можно менять и прямо в Google Sheets.
7. В каждом недельном листе автоматически считаются:
   - суммарный план;
   - суммарный факт;
   - сколько не хватает до цели;
   - сколько нужно добавить к плану каждому из 12 участников.
8. Статистика сайта показывает эти же показатели.
9. Авторизация сохраняется на 7 дней.

УСТАНОВКА

A. GOOGLE APPS SCRIPT

1. Откройте Code.gs из архива.
2. В строке:
   const SITE_PASSWORD = 'ВПИШИТЕ_СЮДА_ВАШ_ТЕКУЩИЙ_ПАРОЛЬ';
   впишите ваш текущий пароль.
3. Полностью замените старый код Apps Script кодом из Code.gs.
4. Нажмите "Сохранить".
5. Выберите функцию setup и запустите ее ОДИН РАЗ.
   Будет создан недельный лист текущей недели и скрытый служебный лист.

Если в старом "Лист1" уже есть введенные данные:
6. Выберите функцию migrateOldData и запустите ее ОДИН РАЗ.
   Старые записи скопируются в соответствующие недельные листы.
   Старый "Лист1" не удаляется.

7. Начать развертывание -> Управление развертываниями -> карандаш.
8. Выберите "Новая версия".
9. Нажмите "Развернуть".
   URL веб-приложения должен остаться прежним.

B. GITHUB

В репозитории замените:
- index.html
- app.js
- style.css

Code.gs в GitHub загружать не обязательно.

КАК ВЫГЛЯДИТ НЕДЕЛЬНЫЙ ЛИСТ

A2: Цель команды
B2: значение цели

A3: Суммарный план
A4: Суммарный факт
A5: Не хватает до цели
A6: Добавить к плану на человека
