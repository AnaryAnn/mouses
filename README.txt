Сычиная охота v6

Лист Google Sheets «Участники» теперь единственный рабочий источник состава.
Новый участник, добавленный ботом или вручную в этот лист, автоматически:
- появляется в поиске сайта;
- учитывается в количестве участников;
- учитывается в расчете дополнительных мышей;
- добавляется в текущий недельный лист при синхронизации.

INITIAL_PEOPLE в Code.gs нужен только для первоначального создания листа с нуля.

Обновление:
1. Заменить Code.gs, вернуть SITE_PASSWORD, выпустить новую версию Web App.
2. В GitHub сайта заменить app.js.
3. В GitHub бота заменить app.py.
4. setup() повторно не нужен, если лист «Участники» уже существует.
