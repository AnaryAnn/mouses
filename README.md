# Сычиная охота

Готовый статический сайт для GitHub Pages.

## Перед публикацией

1. Откройте `app.js`.
2. Найдите:
   `const SITE_PASSWORD = "mouse2026";`
3. Замените `mouse2026` на свой пароль.
4. Загрузите `index.html`, `style.css`, `app.js` в корень GitHub-репозитория.
5. В GitHub: Settings -> Pages -> Deploy from a branch -> main / root.

## Важно о пароле

GitHub Pages является статическим хостингом. Пароль, записанный в JavaScript, можно увидеть в исходном коде страницы. Поэтому текущий пароль защищает интерфейс от случайного доступа, но не является настоящей защитой данных.

Для реальной защиты нужно добавить проверку секретного ключа в Google Apps Script. Также сейчас опубликованный Apps Script endpoint доступен напрямую тому, кто знает его URL.
